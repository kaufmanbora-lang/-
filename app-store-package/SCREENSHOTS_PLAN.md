# Screenshot plan

Prepare screenshots in App Store Connect for iPhone 6.7" and iPhone 6.5" sizes at minimum. Add iPad screenshots if you enable iPad availability.

## Recommended screenshots

1. Login / registration screen with black-blue glass design.
2. Chat list with private chats and bottom iPhone-style navigation.
3. Direct chat with messages, files, and voice controls.
4. Group chat with room features: polls, tasks, events, scheduled messages.
5. Call screen with audio/video controls.
6. Profile and security screen showing session safety and account deletion.
7. Moderation/report/block flow if you want to highlight safety.

## Screenshot copy ideas

- "Private chats and groups"
- "Voice, files and calls"
- "Polls, tasks and events"
- "Optional push notifications"
- "Built-in safety controls"

## Before taking screenshots

- Use real-looking demo users, not placeholders.
- Remove dev codes and test-only text.
- Make sure the server is live and fast.
- Do not show private emails, admin password, API keys, or real personal data.
