# Orbit Chat - App Store listing

## Name

Orbit Chat

## Subtitle

Chats, calls and groups

## Promo Text

A personal messenger with groups, calls, files, voice messages, push notifications, and account safety tools.

## Description

Orbit Chat is a mobile-first messenger for private conversations and groups.

Message friends, create groups, send photos, files and voice messages, start audio or video calls, save important messages, pin content, and receive phone notifications.

Main features:

- private and group chats;
- audio and video calls;
- photos, files, and voice messages;
- avatars and user profiles;
- contacts, favorite chats, and saved messages;
- polls, tasks, and room events;
- scheduled messages;
- push notifications for messages and calls;
- reporting, blocking, and admin moderation;
- email-code registration;
- verified email changes;
- in-app account deletion.

Orbit Chat works across phone, tablet, and desktop through one account and a shared server.

Privacy and control:

- passwords are stored as secure hashes;
- users can revoke other sessions;
- users can report abusive content;
- users can block abusive users;
- users can delete their own account from the Security screen.
