# Orbit+ Update Report

## Mobile Game Fix

- Orbit+ games now have a sticky launcher for Reactor, Memory, and Signal, so the real games stay visible on phone even after scrolling.
- Active games hide the Orbit+ stats and tab grid while playing, which keeps the playable cells inside the first phone viewport.
- Live mobile browser QA passed: Orbit+ bottom tab opens games, Signal/Reactor render a grid, tapping the active cell increases score/combo, and cancel returns to the games menu without saving.

## Что добавлено

- Новый центр `Orbit+` с отдельной кнопкой в верхнем меню.
- Истории на 24 часа с текстом, фото, просмотрами и реакциями.
- Система друзей: поиск по нику/почте, заявки, принятие, отклонение и удаление друга.
- Профиль 2.0: уровень, XP, сила профиля, достижения, публичный NFT-витринный блок.
- Магазин кастомизации за OT: темы, рамки профиля, эффекты сообщений и бейджи.
- Настоящие мини-игры: `Реактор`, `Память`, `Сигнал` с таймером, сеткой, очками, серией и сохранением результата.
- Быстрые мини-режимы: кости, монетка и OT Spin с историей последних игр.
- Кланы: создание, вступление, выход, сила клана по участникам.
- Расширенные достижения: история, реакция на историю, друзья, 3 друга, NFT, свой стиль, клан, активная игра, сильный результат и высокий уровень.
- Нижняя мобильная кнопка `Orbit+`, чтобы игры и достижения открывались с телефона.
- Безопасный режим и тонкая настройка уведомлений.
- Быстрый старт для новых пользователей.
- Live-обновления Orbit+ через SSE без перезапуска приложения.

## Проверки

- `node --check server.js`
- inline-проверка JavaScript из `index.html`
- `node qa-check.js`
- API smoke test: регистрация 2 аккаунтов, друзья, история, реакция, удаление друга, магазин, мини-игра, клан, настройки, личное сообщение.
- `node orbit-plus-smoke-test.js` / `npm run smoke:orbit`: реальный HTTP smoke-test новых функций с очисткой тестовых аккаунтов.
- Мобильная browser-проверка вкладок Orbit+: истории, друзья, профиль, магазин, игры, кланы, безопасность, старт.
- Мобильная browser-проверка нижней кнопки Orbit+ и активной игры `Реактор`: старт, попадание по клетке, серия/очки, отмена без награды.
- Проверка консоли браузера: ошибок нет.

## Важно
