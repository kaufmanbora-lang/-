# Orbit Chat QA Report

Дата проверки: 2026-06-13

## Версия

- `package.json`: `1.2.0`
- `/api/health`: должен отдавать `version: 1.2.0`

## Проверено автоматически

- `server.js` проходит синтаксическую проверку Node.
- `sw.js` проходит синтаксическую проверку Node.
- `manifest.json` валидный и содержит PWA-иконки.
- Клиентский JavaScript внутри `index.html` парсится без ошибок.
- В приложении есть кнопка и панель `Безопасность`.
- EventSource больше не использует `/api/events?token=...`.
- Новые сессии не записывают auth-токен в `localStorage`.
- `server.js` содержит allowlist статических файлов.
- Wildcard CORS `access-control-allow-origin: *` удален.
- Есть HttpOnly cookie-сессия `orbit_session`.
- Есть проверка силы пароля.
- Есть блокировка повторных неправильных входов.
- Есть проверка доступа к загруженным файлам.
- Есть проверка MIME по сигнатуре файла.
- Есть Content Security Policy.
- Есть сброс других сессий.
- Есть fallback для `DATA_DIR`, чтобы Render не падал при проблеме с `/var/data`.

## Security Smoke

- `/server.js` возвращает `404`.
- `/data/orbit-chat-data.json` возвращает `404`.
- `/api/health` возвращает `version: 1.2.0`.
- В `/api/health` нет `access-control-allow-origin: *`.
- Регистрация со слабым паролем возвращает `400`.
- Регистрация с сильным паролем выдает `Set-Cookie` с `HttpOnly` и `SameSite=Lax`.
- `/api/security` работает по cookie-сессии.
- Отправка сообщения работает по cookie-сессии без `Authorization` header.
- Вложение из сообщения без cookie возвращает `401`.
- То же вложение с cookie возвращает `200`.
- Файл с поддельным MIME `image/png` возвращает `400`.
- `/api/security/revoke-other-sessions` возвращает `200`.

## Ручная проверка после Render

1. Открой `https://твоя-ссылка.onrender.com/api/health`.
2. Убедись, что там `version: 1.2.0`.
3. Зарегистрируй новый аккаунт с паролем минимум 10 символов, буква и цифра.
4. Открой приложение, нажми кнопку со щитом `Безопасность`.
5. Проверь, что панель показывает активные входы.
6. Нажми `Сбросить другие входы`.
7. Попробуй открыть внутренний файл через браузер, например `/server.js` - должен быть `Not found`.
8. Попробуй открыть `/data/orbit-chat-data.json` - должен быть `Not found`.

## Ограничение

Push на экран блокировки, камера и микрофон полноценно проверяются только на опубликованной HTTPS-ссылке Render. Локальный `127.0.0.1` не заменяет опубликованный сайт для телефона друга.
