# Orbit Chat QA Report

Дата проверки: 2026-06-12

## Проверено

- `server.js` проходит синтаксическую проверку Node.
- `sw.js` проходит синтаксическую проверку Node.
- `manifest.json` валидный и содержит `display: standalone`.
- В manifest подключены PNG/SVG-иконки приложения.
- `index.html` содержит валидный клиентский JavaScript.
- Серверный push-поток проверен через QA-подмену `web-push`:
  - тестовое push-уведомление;
  - push нового сообщения;
  - push входящего видеозвонка.
- Push payload использует PNG-иконки: `/icon-192.png` и `/maskable-icon-512.png`.
- Проверено ограничение push-подписок: после 11 устройств у аккаунта остаётся 10 свежих подписок.
- Проверена отписка текущего устройства от push: после удаления endpoint подписок остаётся 0.
- Проверен локальный fallback кнопки `Тест`, когда `web-push` не установлен локально.
- Проверены HTTP security headers на `/api/health`: `x-content-type-options`, `referrer-policy`, `permissions-policy`.
- Проверено PWA-офлайн открытие: после регистрации service worker новая вкладка открывает оболочку без сети.
- Браузерный smoke-test:
  - приложение открывается;
  - service worker регистрируется;
  - панель уведомлений открывается на мобильном размере;
  - кнопки `Включить`, `Установить`, `Тест`, `Закрыть` видны на телефоне;
  - бейдж непрочитанных сообщений появляется в списке чатов;
  - заголовок вкладки получает счётчик непрочитанных.
- Zip-пакет распакован во временную папку и прошёл `qa-check.js`.
- `qa-check.js` дополнительно проверяет `package.json` версии `1.1.3`, кнопку копирования ссылки на приложение, аудиозвонок, кнопку приглашения в звонок, ICE-очередь, выбор MIME для голосовых и `healthCheckPath: /api/health` в `render.yaml`.
- `/api/health` отдаёт `version: 1.1.3`.
- API-smoke на временной чистой базе прошёл: регистрация двух аккаунтов, вход, отправка личного сообщения и unread-счётчик получателя.
- Call API-smoke на временной чистой базе прошёл: входящий `offer` сохраняется как call invite, отдаётся получателю через SSE после подключения и очищается после `reject`.
- Voice API-smoke на временной чистой базе прошёл: `data:audio/webm;codecs=opus;base64,...` сохраняется как `kind: audio`, нормализуется в `audio/webm` и отдаётся по `/uploads/...webm`.
- Локальный сервер поднят на `http://127.0.0.1:8790/` и после паузы продолжает отвечать.
- `manifest.json` по HTTP отдаёт `display: standalone`, 5 иконок и 2 shortcut-действия.
- `sw.js` по HTTP отдаётся как `application/javascript` с security headers.
- `/icon-192.png` по HTTP отдаётся как `image/png`.

## Команды

```bash
npm install
npm run check
npm start
```

## Важное ограничение

Настоящее push-уведомление на экран блокировки телефона проверяется после деплоя на HTTPS-ссылке Render и после разрешения уведомлений на самом телефоне. Локальный `127.0.0.1` не заменяет опубликованный HTTPS-сайт для друга.
