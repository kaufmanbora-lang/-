# Orbit Chat

Мобильный веб-мессенджер с регистрацией, входом, общим чатом, личными сообщениями и живыми обновлениями.

## Что есть

- регистрация по email, нику и паролю;
- вход в аккаунт;
- общий чат для всех игроков/друзей;
- личные сообщения между пользователями;
- групповые чаты;
- видеозвонки 1-на-1 в личных чатах;
- групповые видеозвонки из группового чата;
- аудиозвонки без камеры;
- устойчивее входящие звонки после push/перезагрузки приложения;
- диагностика звонка и кнопка приглашения в окне звонка;
- отправка фото и файлов;
- отправка файлов до 25 МБ;
- голосовые сообщения;
- устойчивые голосовые сообщения в разных браузерах: webm/opus, ogg, mp4, aac;
- реакции на сообщения;
- редактирование и удаление своих сообщений;
- закрепленные сообщения в чате;
- поиск внутри выбранного чата;
- отметки прочтения и статус "печатает";
- бейджи непрочитанных сообщений в списке чатов и в заголовке приложения;
- аватарки аккаунтов до 8 МБ;
- сохранение людей в контакты;
- просмотр профилей людей;
- уведомления через браузер и push-подписки;
- PWA-режим: manifest, иконка приложения, service worker и установка на телефон;
- панель диагностики уведомлений с тестовым push;
- кнопка копирования ссылки на приложение в панели уведомлений;
- push-уведомления для новых сообщений и входящих звонков;
- список людей и поиск;
- мобильный интерфейс для телефона;
- серверная база в JSON-файле;
- готовый `render.yaml` для публикации на Render.

## Локальный запуск

```bash
npm install
npm start
```

Проверка перед загрузкой:

```bash
npm run check
```

Открыть:

```text
http://127.0.0.1:8790
```

## Важно

Чтобы чат работал из любой страны и компьютер не должен был быть включен, проект нужно загрузить на GitHub и развернуть на Render. Для надежного хранения аккаунтов и сообщений используется Render Disk.

Для видеозвонков на телефоне открывай опубликованную HTTPS-ссылку Render. На обычной локальной `http://192.168...` ссылке телефон может не дать камеру, потому что браузеры требуют HTTPS. В группе нажми кнопку камеры сверху: приглашение уйдет участникам группы.

Push-уведомления используют пакет `web-push`. Render установит его автоматически через `npm install`. После входа в аккаунт нажми колокольчик в приложении, нажми `Включить`, разреши уведомления на телефоне и нажми `Тест`.

Для экрана блокировки на iPhone сайт должен быть открыт по HTTPS, добавлен на главный экран через Safari и запущен через иконку приложения.

Подробная инструкция для телефона лежит в `PHONE_PUSH_GUIDE.md`.
