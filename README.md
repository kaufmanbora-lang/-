# Orbit Chat

Мобильный веб-мессенджер с регистрацией, входом, общим чатом, личными сообщениями и живыми обновлениями.

## Что есть

- регистрация по email, нику и паролю;
- вход в аккаунт;
- общий чат для всех игроков/друзей;
- личные сообщения между пользователями;
- отправка фото и файлов;
- аватарки аккаунтов;
- сохранение людей в контакты;
- список людей и поиск;
- мобильный интерфейс для телефона;
- серверная база в JSON-файле;
- готовый `render.yaml` для публикации на Render.

## Локальный запуск

```bash
npm install
npm start
```

Открыть:

```text
http://127.0.0.1:8790
```

## Важно

Чтобы чат работал из любой страны и компьютер не должен был быть включен, проект нужно загрузить на GitHub и развернуть на Render. Для надежного хранения аккаунтов и сообщений используется Render Disk.
