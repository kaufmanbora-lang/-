## Вход администратора

На экране входа есть отдельное поле `Пароль администратора`.

Если ввести правильный админ-пароль, приложение зайдет в служебный аккаунт `Администратор`. В профиле любого найденного пользователя появится кнопка `Админ: забанить`.

На Render пароль можно поменять через переменную:

```text
ADMIN_LOGIN_PASSWORD=твой-новый-пароль
```

## Почта для восстановления пароля

Регистрация и смена почты работают без кода. Почта нужна только для писем восстановления пароля. Если восстановление пароля должно реально приходить, на Render нужно добавить SMTP или Resend.

SMTP:

```text
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=your-user
SMTP_PASS=your-password
SMTP_FROM=Orbit Chat <no-reply@your-domain.com>
PUBLIC_APP_URL=https://твоя-ссылка.onrender.com
```

Или Resend:

```text
RESEND_API_KEY=your-resend-key
MAIL_FROM=Orbit Chat <no-reply@your-domain.com>
PUBLIC_APP_URL=https://твоя-ссылка.onrender.com
```

Без этих переменных приложение не сможет физически отправить письмо на почту.

## База данных для настоящего релиза

Самый простой режим работает через JSON-файл. Для настоящего сайта лучше добавить PostgreSQL и переменную:

```text
DATABASE_URL=postgresql://...
```

Если `DATABASE_URL` есть, Orbit Chat хранит аккаунты, сообщения, группы, жалобы, настройки и новые загрузки файлов в PostgreSQL. JSON остаётся локальной резервной копией.

На Render можно создать PostgreSQL отдельно, скопировать Internal Database URL и вставить его в `Environment` сервиса Orbit Chat.

## Локальный запуск

```bash
npm install
npm start
```

Проверка перед загрузкой:

```bash
npm run check
```

Открыть:

```text
http://127.0.0.1:8790
```

На этом компьютере можно просто два раза нажать `START_APP.bat`: он запустит сервер и откроет правильную ссылку.

## Важно

Чтобы чат работал из любой страны и компьютер не должен был быть включен, проект нужно загрузить на GitHub и развернуть на Render. Для надежного хранения аккаунтов, сообщений и файлов подключи PostgreSQL через `DATABASE_URL`.

Для видеозвонков на телефоне открывай опубликованную HTTPS-ссылку Render. На обычной локальной `http://192.168...` ссылке телефон может не дать камеру, потому что браузеры требуют HTTPS. В группе нажми кнопку камеры сверху: приглашение уйдет участникам группы.

Push-уведомления используют пакет `web-push`. Render установит его автоматически через `npm install`. После входа в аккаунт нажми колокольчик в приложении, нажми `Включить`, разреши уведомления на телефоне и нажми `Тест`.

Для экрана блокировки на iPhone сайт должен быть открыт по HTTPS, добавлен на главный экран через Safari и запущен через иконку приложения.

Подробная инструкция для телефона лежит в `PHONE_PUSH_GUIDE.md`.
