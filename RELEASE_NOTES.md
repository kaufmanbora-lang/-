# Orbit Chat 1.1.1 - Grand Push/PWA Update

## Что добавлено

- PWA-режим: `manifest.json`, SVG/PNG-иконки приложения и maskable-иконка.
- Улучшенный `sw.js`: кэш оболочки, нормальные push-уведомления, иконка, бейдж, вибрация и открытие нужного чата.
- Панель уведомлений по кнопке колокольчика.
- Проверка статуса: браузер, HTTPS, разрешение телефона, сервер push, подписка устройства и режим приложения.
- Кнопка тестового push-уведомления.
- Push для новых сообщений.
- Push для входящих видеозвонков.
- Открытие нужного чата из уведомления через `?room=...`.
- Счётчики непрочитанных сообщений в списке чатов.
- Бейдж непрочитанных в заголовке вкладки и через Badging API, если браузер поддерживает.
- Плашка “нет интернета” и автообновление после возвращения сети.
- Команда `npm run check` для проверки сервера, service worker, manifest и клиентского JS.
- `QA_REPORT.md` с результатами проверок новой версии.
- `TROUBLESHOOTING.md` с быстрыми ответами по push, Render и телефону.
- `PHONE_PUSH_GUIDE.md` с отдельной инструкцией для iPhone и Android.
- `/api/health` и `healthCheckPath` для Render.
- `/api/health` показывает версию `1.1.1`.
- PWA shortcuts: быстрый вход в общий чат и панель уведомлений.
- Ограничение до 10 push-устройств на аккаунт, чтобы база не разрасталась старыми подписками.
- Rate limit для тестовых push-уведомлений.
- Отписка текущего устройства от push при выходе из аккаунта.
- Локальный fallback для кнопки `Тест`, если Render push ещё не готов.
- Базовые HTTP security headers: `nosniff`, `no-referrer`, permissions policy.
- `aria-label` для иконок-кнопок и строк чатов с непрочитанными.
- Кнопка копирования ссылки на текущий чат.
- Кнопка копирования ссылки на приложение в панели уведомлений, чтобы быстрее открыть Render-сайт на телефоне или отправить другу.
- Обновлённая инструкция для GitHub и Render.

## Как проверить уведомления на телефоне

1. Загрузи новую версию на GitHub.
2. Дождись деплоя Render.
3. Открой HTTPS-ссылку Render на телефоне.
4. Войди в аккаунт.
5. На iPhone: Safari -> Поделиться -> На экран Домой.
6. Открой Orbit Chat через иконку на главном экране.
7. Нажми колокольчик.
8. Нажми `Включить`.
9. Разреши уведомления.
10. Нажми `Тест`.

## Важно

На локальной ссылке `http://127.0.0.1:8790` телефонные push-уведомления для друга не проверяются как настоящая публикация. Для экрана блокировки нужна опубликованная HTTPS-ссылка Render.

Если в панели написано, что сервер push не готов, значит на локальном компьютере не установлен пакет `web-push`. На Render он ставится автоматически через `npm install`, потому что он указан в `package.json`.
