# Orbit Chat 1.2.0 - Security Upgrade

## Главное

- Закрыт доступ к внутренним файлам проекта через браузер. Сервер теперь отдает только публичные файлы приложения.
- Добавлена HttpOnly cookie-сессия `orbit_session`.
- Live-события больше не передают auth-токен в URL.
- Новые сессии больше не сохраняют auth-токен в `localStorage`; старый токен используется только один раз для миграции и удаляется.
- Добавлена панель `Безопасность` в приложении.
- Добавлен endpoint `/api/security` для просмотра активных сессий.
- Добавлен endpoint `/api/security/revoke-other-sessions` для сброса других входов.
- Новые пароли должны быть минимум 10 символов, с буквой и цифрой.
- Хеширование паролей усилено до PBKDF2-SHA256 с 310,000 итераций.
- Старые пароли автоматически обновляются после успешного входа.
- После нескольких неверных попыток вход блокируется на 15 минут для этой почты/IP.
- Загрузки файлов теперь проверяются по содержимому, а не только по MIME от браузера.
- SVG-загрузки заблокированы.
- `/uploads/...` теперь требует вход и проверяет доступ пользователя к аватару или комнате сообщения.
- Добавлены сильнее security headers: CSP, HSTS, frame blocking, no-sniff, referrer policy, permissions policy.
- API блокирует опасные запросы с чужих origin.
- Ошибки сервера больше не показывают пользователю внутренние пути и технические детали.
- Для звонков добавлена проверка доступа к комнате звонка.
- Добавлены лимиты на профиль, группы, контакты, push-подписки и смену пароля.

## Render

- `/api/health` должен показывать `version: 1.2.0`.
- Для постоянного хранения лучше оставить Render Disk с `DATA_DIR=/var/data`.
- Если хочешь контролировать секрет сессий сам, добавь в Render переменную `SESSION_SECRET` с длинным случайным значением.

## Проверка

```bash
npm install
npm run check
npm start
```

Потом открой:

```text
http://127.0.0.1:8790/api/health
```

В ответе должна быть версия `1.2.0`.

## Важно

Ни один реальный сайт нельзя сделать абсолютно невзламываемым навсегда. Эта версия закрывает главные практические риски текущего проекта и делает основу намного сильнее для публикации.
