# Orbit Chat Troubleshooting

## Уведомление не приходит на телефон

Проверь по порядку:

1. Сайт открыт по HTTPS-ссылке Render, а не через `127.0.0.1`.
2. Ты вошёл в аккаунт.
3. На iPhone сайт добавлен на главный экран и открыт через иконку Orbit Chat.
4. В панели колокольчика пункт `Разрешение телефона` зелёный.
5. В панели колокольчика пункт `Сервер push` зелёный.
6. В панели колокольчика пункт `Это устройство` зелёный.
7. В настройках телефона уведомления для Orbit Chat не выключены.

## Почему локально пишет, что сервер push не готов

Локальная папка может быть без установленного `web-push`. На Render пакет ставится командой `npm install`, потому что он указан в `package.json`.

## Почему на iPhone нужно добавлять на главный экран

iPhone показывает Web Push как уведомления приложения для web-приложений, добавленных на главный экран. Обычная вкладка Safari не всегда ведёт себя как установленное приложение.

## Почему другу нужна Render-ссылка

`127.0.0.1` и `localhost` работают только на твоём компьютере. Другу нужна публичная HTTPS-ссылка Render вида:

```text
https://orbit-chat-xxxx.onrender.com
```

## Почему Render показывает 502 Bad Gateway

Это значит, что Render открыл ссылку, но приложение внутри сервера не ответило. Самые частые причины:

1. Deploy ещё идёт или сервис только просыпается.
2. Сервер упал при запуске.
3. На Render не установились зависимости.
4. Не подключился диск `/var/data`.
5. Открыта старая версия после неудачного deploy.

Что делать:

1. Открой Render.
2. Зайди в сервис `orbit-chat`.
3. Открой вкладку `Logs`.
4. Нажми `Manual Deploy` -> `Deploy latest commit`.
5. Дождись строки вида `Orbit Chat 1.1.4 is running`.
6. Открой `https://твоя-ссылка.onrender.com/api/health`.

Если `/api/health` показывает `version: 1.1.4`, сервер живой. Если там ошибка, пришли скрин логов Render.

В версии `1.1.4` добавлена защита: если диск `/var/data` недоступен, приложение не падает, а запускается с временным хранилищем в папке `data`. Для настоящего постоянного хранения аккаунтов и сообщений лучше всё равно подключить Render Disk.

## Что делать после загрузки новой версии на GitHub

1. Открой Render.
2. Зайди в свой сервис Orbit Chat.
3. Если деплой не начался сам: `Manual Deploy` -> `Deploy latest commit`.
4. Дождись зелёного статуса.
5. Открой ссылку Render и нажми колокольчик -> `Тест`.
